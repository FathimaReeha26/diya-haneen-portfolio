## 🌐 Free 1-Click Deployment Options

### Option A: GitHub Pages
1. Push this folder to a GitHub repository (e.g. `diyahaneen/portfolio`).
2. Go to **Settings > Pages**.
3. Under "Branch", select `main` (or `master`) and folder `/ (root)`.
4. Click **Save** — your site is now live at `https://<username>.github.io/<repo>/`!

### Option B: Netlify or Vercel
- Drag and drop the `DIYA PORTFOLIO` directory straight onto the [Netlify Drop](https://app.netlify.com/drop) or [Vercel](https://vercel.com) dashboard for instant SSL-secured hosting.
